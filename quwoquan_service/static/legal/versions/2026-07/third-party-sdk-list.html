版本号：2026-07 ｜ 生效日期：2026 年 7 月 5 日

本清单披露当前工程版本涉及的第三方 SDK、开源插件、系统能力或预留能力。生产发布前应以最终 iOS PrivacyInfo.xcprivacy、Android 数据安全表单、依赖锁文件和实际接入 SDK 为准复核。

一、当前免费社区版本说明

当前免费社区版本默认不启用广告 SDK、支付 SDK、自动续费 SDK、商业化埋点 SDK 或第三方追踪脚本。微信、QQ、支付宝等入口如仅为非生产沙箱或 UI 预留，不代表生产环境已接入对应 SDK 或向对应第三方共享个人信息。

三、外部平台内容说明

图虫、微信、今日头条、微博、小红书等平台可能作为用户分享、外链打开、授权登录、内容发现参考或来源核验对象出现。除本清单明确启用的 SDK 或您主动打开、分享、授权的场景外，趣我圈不会默认向这些平台共享您的个人信息，也不会默认下载或发布未授权的平台素材。

四、更新机制

任何新增 SDK、变更提供方、扩大数据处理范围、启用广告或支付能力前，必须先更新本清单和隐私政策，经法务审核后通过 legal-static 独立发布。若变更影响用户重大权益，应以显著方式提示并在必要时重新取得授权或同意。

五、联系方式

如您对第三方 SDK 或个人信息共享有疑问，可联系 privacy@quwoquan.com 或 support@quwoquan.com。
