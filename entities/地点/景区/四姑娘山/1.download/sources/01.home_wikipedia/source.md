# 四姑娘山

四姑娘山位于四川省阿坝藏族羌族自治州小金县四姑娘山镇境内，地处邛崃山脉中段，毗邻卧龙国家级自然保护区和米亚罗自然保护区。1994年、1996年先后被国务院批准建立四姑娘山国家重点风景名胜区和小金四姑娘山国家级自然保护区，也是世界自然遗产「四川大熊猫栖息地」的重要组成部分。

景区由四座相连的山峰组成，主峰幺妹峰海拔6250米，有「东方的阿尔卑斯」之称。三条主要游览沟——双桥沟、长坪沟、海子沟——是大多数游客进入景区的主要通道。

# 门票与交通（公开信息摘要）

- 双桥沟：门票约80元/人，观光车约70元/人
- 长坪沟：门票约70元/人，观光车约20元/人
- 海子沟：门票约60元/人，以徒步/骑马为主
- 从成都出发，通常经映秀、卧龙、翻越巴朗山抵达四姑娘山镇，车程约4–5小时
