# L3 Story：interest-onboarding-prior

## 功能说明

新用户兴趣先验通过可跳过的兴趣采集，把标签、垂类、地点和内容类型偏好写入用户画像初始状态，用于首刷召回和排序保底。

## 范围

- 兴趣维度：标签、频道/垂类、地点/实体、内容类型。
- 与登录解耦：游客可跳过，有默认探索保底；登录后可同步到账号画像。
- 写入用户画像先验，供 FeatureProvider/HotPath 首刷消费。
- 冷启动首刷非空率进入 `cold_start_non_empty_rate`。

## 非目标

- 本轮不实现 App onboarding 页面或用户画像写入。
- 不在 UI 中直接判断数据源或推荐模式。

## 验收标准

- A1：兴趣先验字段 metadata-first，不能在 UI 本地维护第二套标签列表。
- A2：跳过 onboarding 不阻塞首刷。
- A3：游客与登录态的先验合并语义清晰。
- A4：首刷非空率和负反馈率进入推荐 SLO。
