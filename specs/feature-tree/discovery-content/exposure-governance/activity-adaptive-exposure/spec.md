# L3 Story：activity-adaptive-exposure

## 功能说明

不同活跃度用户需要不同的曝光策略。新用户需要更多探索和质量保底，活跃用户需要更严格的疲劳与频控，沉默回流用户需要适度复活和高置信内容。

## 用户分群

- `cold_start`：无行为或行为极少。
- `active`：近期多次消费和互动。
- `returning`：沉默后回流。
- `low_confidence`：画像不稳定或信号冲突。

## 范围

- 按分群配置 served/impressed 窗口长度。
- 按分群配置探索比、复活比、频控强度和保底来源。
- 活跃度分群仅作为策略输入，不在 UI 层分叉体验。

## 非目标

- 本轮不实现分群计算或画像写入。
- 不在 App 层硬编码用户活跃度判断。

## 验收标准

- A1：用户活跃度分群来自服务端画像或 feature store，端侧不判断平台或分群。
- A2：窗口、探索比和复活比来自 recpolicy。
- A3：`activity_segment` 进入 AB 与 SLO 切分标签。
- A4：分群缺失时回退默认策略。
