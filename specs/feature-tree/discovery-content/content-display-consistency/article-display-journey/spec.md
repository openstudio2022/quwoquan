# L3 Story：article-display-journey（文章展示与阅读旅程） (`article-display-journey`)

> 所属能力：[`content-display-consistency`](../spec.md)

> Journey / Scenario：[`JNY-003 / SCN-007`](../../../spec.md#scn-007)

> 设计归属：[L2 DEC-001](../design.md#dec-001)

## 1. 用户价值

作为内容创作者或浏览者，
我希望整个卡片为统一热区，点击直接进入文章沉浸式阅读器，
从而完成可恢复的内容创作、发现或互动。

## 2. 范围与非目标

### Out of Scope

## 3. 行为要求

<a id="req-001"></a>
### REQ-001 article-display-journey（文章展示与阅读旅程）

- 整个卡片为统一热区，点击直接进入文章沉浸式阅读器。

<a id="req-002"></a>
### REQ-002 卡片上可显示轻量“文章”语义标签，但不能喧宾夺主

- 卡片上可显示轻量“文章”语义标签，但不能喧宾夺主。
- 整个卡片为统一热区，点击直接进入文章沉浸式阅读器。
- 圈子频道中的文章卡用于高密度浏览与审美辨识，必须适配双列瀑布流。
- 卡面可继承模板的弱纸张语义，如淡纸纹、淡页边、轻装订感，但不得重到影响信息阅读。
- 圈子双列文章卡点入后同样进入统一的文章沉浸式阅读器，不允许分叉到另一套“详情页”。
- 阅读器必须满足。
- 顶部导航位于安全区内独立悬浮，正文页从导航下方开始，不得侵入顶部工具栏区域。
- 页码统一规则。
- 位置统一放在返回按钮之后，与图片组查看器保持相同导航语义。
- 拖拽页角时必须允许用户停留在中间状态；松手后按阈值自动完成翻页或回弹。
