# L3 Story：作品统一内容流 (`works-unified-feed`)

> 所属能力：[`dual-rail-discovery-redesign`](../spec.md)
>
> Journey / Scenario：[`JNY-003 / SCN-007`](../../../spec.md#scn-007)
>
> 设计引用：[L2 DEC-001](../design.md#dec-001)

## 1. 用户价值

作为浏览内容的用户，
我希望在同一内容流发现图片、视频和文章，从任意媒体预览进入对应聚焦面，
从而连续浏览并在返回后保留原内容位置与互动结果。

## 2. 范围与非目标

### In Scope

- 三类 Post 在同一内容流中的浏览、打开与返回。
- 图片集合的等高宫格预览、媒体定位及失败隔离。

### Out of Scope

- 以内容身份划分的作品轨与点滴轨；新 Surface、推荐排序算法或新契约取值。
- 聚焦面中的翻页、播放器和评论交互细节，由作品沉浸式浏览器 Story 拥有。

## 3. 行为要求

<a id="req-001"></a>
### REQ-001 同一内容流按权威目的面打开

- 图片、视频、文章在同一内容流按服务端结果呈现，不按退役身份拆分入口或重新排序。
- 点击采用出站目的面，图片与视频进入媒体聚焦面，文章进入文章阅读面；可共用浏览器壳，不将壳名称当作内容身份。
- 返回保留来源列表、cursor、当前项与已有互动结果；读取失败不改跳无关 feed，也不伪造空白成功。

<a id="req-002"></a>
### REQ-002 图片宫格稳定且任意媒体可定位打开

- 含多张图片的预览宫格中，同一行图片使用统一高度与既定裁切；加载成功或失败不改变已分配的宫格位置。
- 用户点击任一图片或视频预览，聚焦面初始定位到该 Post 的所选媒体，关闭后恢复原列表位置。
- 图片有无配文均沿图片内容路径，配文不与图片形成文章段落混排；文章内插图仍属于原文章。
- 卡片内部媒体宫格与页面级列数是不同边界；页面列数仅由 canonical SurfaceLayoutPolicy 决定。

<a id="req-003"></a>
### REQ-003 首页双行顶栏为大搜索框加带字小趣，下方全宽一级 Tab

- 安全区只计算一次；上方搜索框占满剩余宽度，小趣紧随其右侧并显示现有「找小趣」标签；下方一级 Tab 独立占满内容宽度。
- 保留搜索 scope=`all`、来源上下文、返回位置、主题和不小于 44pt 热区；Tab 居中/锚定阈值按实际宽度重算。不恢复过期页面、路由或旧助手半屏。
- 首页状态栏安全区与搜索行共用连续品牌蓝底，覆盖屏幕顶端至搜索行下沿；状态栏图标为浅色，小趣标签在蓝底保持可读。一级 Tab 使用独立中性表面，正文不铺蓝；其他页面的默认搜索样式不变。

<a id="req-004"></a>
### REQ-004 首页正文末行全文入口

- 普通 post 超过折叠行数时，在真实可见末行尾部内联「…全文」，点击只原地展开；展开后内联「收起」恢复折叠，不导航。
- 文章摘要超过三行时，在真实第三行尾部内联「…全文」；点击只打开当前文章阅读器一次，与文章整卡使用同一打开动作，不触发普通 post 展开。
- 两类入口共用字素边界截断与真实排版测量，遵循当前 TextScaler、文本方向及 locale，不切断 emoji/组合字符；短文不显示多余入口。入口整体不得断行，其独立最小 44pt 热区参与行内排版，不用覆盖正文的定位热区或另起一行补入口。
- 「…」与相邻正文同字重、同颜色，不得加粗。「全文」与「收起」与正文同字重，颜色使用首页可点实体同一 slogan-accent token，不得加粗、不得使用 iosAccent 或 primaryColor。

## 5. 验收场景

<a id="gwt-001"></a>
### GWT-001 混排流打开与返回不中断上下文

- GIVEN 已加载的同一列表包含图片、视频和文章，用户停留在非首项且存在下一页 cursor。
- WHEN 用户分别打开各类内容、完成一次赞操作并返回列表。
- THEN 每次均打开出站声明的目的面，返回后保持原项、列表位置、cursor 与已确认的赞状态，不出现点滴轨或媒体嗅探分流。
- AND 当前项读取失败时保留返回与 canonical 恢复动作，其他已加载项仍可浏览。

<a id="gwt-002"></a>
### GWT-002 等高宫格与所选媒体定位

- GIVEN 图片内容包含横图、竖图与一张加载失败图片，并分别有配文和无配文样本。
- WHEN 用户观察宫格加载过程、点击第二张图片进入聚焦面，再关闭返回。
- THEN 同行预览保持等高与稳定位置，失败仅影响对应格；初始聚焦第二张图片且返回恢复原列表位置。
- AND 配文保持独立区域，不插入媒体序列，不因配文或加载结果变成文章。

<a id="gwt-004"></a>
### GWT-004 首页双行搜索与小趣头部

- GIVEN 用户打开首页。
- WHEN 顶栏完成布局。
- THEN 上方出现大搜索框与带字小趣，下方一级 Tab 占满内容宽度；搜索与小趣入口可进入当前搜索/助手旅程。
- AND 深浅主题、文字放大、窄屏与平板下热区不小于 44pt；Tab 锚定与反向恢复仍成立。
- AND 安全区与搜索行蓝底连续、恰在独立中性 Tab 上沿终止，状态栏为浅色前景，小趣标签保持可读；正文及全站其他搜索入口底色不变。

<a id="gwt-003"></a>
### GWT-003 首页全文入口保留末行与不同动作

- GIVEN 首页展示短文、长普通 post 与长文章摘要，包含 emoji/组合字符，使用窄屏、放大文字或 RTL 排版。
- WHEN 文本按当前宽度布局。
- THEN 短文不出现全文；两种长文的完整「…全文」位于折叠末行且不覆盖正文，截断前缀保持完整字素，测量与渲染使用相同文字缩放和方向，省略号与正文同色同重，全文与收起与正文同字重、颜色为首页可点实体 slogan-accent 且不得使用 iosAccent 或 primaryColor，均不得呈现为粗体。
- WHEN 点击普通 post 全文、再点击收起，或点击文章全文。
- THEN 普通 post 只原地展开/收起且不导航；文章全文只打开当前阅读器一次，点击整卡仍走同一打开动作；各入口热区至少 44pt 且不侵占相邻正文。

### OPEN-001 统一内容流与宫格交接验收证据

- 类型：`capability_gap`
- 优先级：`P1`
- 准出影响：`track`
- 影响或价值：尚缺当前单轨混排流的真实导航、互动回流、等高宫格与所选媒体定位证据；旧轨入口退役不等于交互已实现。
- 完成判定：`GWT-001`、`GWT-002` 对应行为满足且真实测试 `spec_ref` 有效。

<a id="open-002"></a>
### OPEN-002 首页双行搜索与小趣头部证据待双端旅程

- 优先级：`P1`
