# L3：对象分享卡片设计（object-share-cards）

> 归属：product-ops-growth / outbound-share-distribution / object-share-cards
> 视角：设计师 + 运营 + 产品。目标是让 5 类对象在微信/海报/口令等站外触点**美观、有吸引力、能驱动点击与回流**。

## 一、功能定位

定义 5 类对象（内容 post 四形态、实体主页、用户、圈子、「我」=user）在各对外渠道的**卡片视觉系统与文案策略**：

- 微信会话卡（OpenSDK `WXMediaMessage`）
- 微信朋友圈卡（OpenSDK 朋友圈场景）
- 海报图（自绘 PNG，含二维码 + 口令）
- 口令文案（剪贴板可识别码）

卡片只消费 `ObjectShareSeed`（见 L2 design）与 `link_templates` 链接，不持有对象业务数据。

## 二、统一视觉原则（吸引点击）

1. **信息层级三段式**：视觉钩子（主图/头像）→ 价值点（标题 + 一句话亮点 + 社交证明数字）→ 行动指令（「打开趣窝圈查看」+ 二维码/口令）。
2. **社交证明前置**：把赞/成员/作品/评分等数字做成「亮点徽标」，制造从众与稀缺感。
3. **品牌一致**：统一品牌色带、Logo、圆角与留白；海报右下固定品牌 + 二维码区。
4. **缩略图安全**：人脸/水印/敏感内容过滤（对接内容安全）；缺图时用品牌占位与对象类型色块。
5. **设计 token**：所有色/距/字走 `AppColors/AppSpacing/AppTypography`；文案走 `UITextConstants`/`l10n`，禁止字面量（rule R27）。
6. **可读对比**：主图上文字加渐变蒙版保证对比度；深浅主题导出统一为分享中性底。

## 三、微信卡片规格（受 OpenSDK 约束）

通用约束：标题（`title`）建议 ≤ 30 字，描述（`description`）≤ 60 字，缩略图（`thumbData`）压缩后 ≤ 32KB、建议 5:4 或 1:1。会话卡与朋友圈卡共用素材，朋友圈以图为主、文案更短。

各对象映射：

- **内容 / 文章（article）**：title=文章标题；desc=摘要首句；thumb=封面（1.91:1 裁切到 5:4 安全区）。亮点：作者 + 阅读量。
- **内容 / 图文（photo）**：title=正文首句或「@作者 的图文」；desc=话题标签；thumb=主图。亮点：图片张数 + 赞数。
- **内容 / 视频（video）**：title=视频标题/首句；desc=时长 + 话题；thumb=首帧 + 居中播放角标。亮点：播放量。
- **内容 / 动态（micro）**：title=「@作者 的动态」；desc=正文摘要；thumb=首图或作者头像底纹。亮点：赞 + 评论。
- **实体主页**：title=实体名 + 品类；desc=一句话简介/地址；thumb=封面。亮点：评分 + 评价数。
- **用户主页**：title=昵称 + 「的主页」；desc=简介首句；thumb=头像（圆形裁切到方图带品牌底）。亮点：作品数 + 粉丝数。
- **圈子**：title=圈子名；desc=圈子简介；thumb=封面。亮点：成员数 + 本周活跃。

## 四、海报规格（自绘 PNG，含二维码 + 口令）

- 画布：1080×1920（9:16，竖版朋友圈/保存相册友好），安全边距走 `AppSpacing`。
- 分区（自上而下）：
  1. 主视觉区（约 60%）：对象主图/头图 + 底部渐变蒙版。
  2. 价值区：标题（大字重）+ 一句话亮点 + 社交证明徽标行。
  3. 作者/归属区：头像 + 昵称/圈子/实体名。
  4. 品牌行动区（固定底部）：趣窝圈 Logo + slogan + 二维码（指向短链 `s/{token}`）+ 口令短码。
- 各对象差异：视频海报主视觉带时长角标；图文海报主视觉可九宫格拼贴；文章海报主视觉=封面+标题压字；用户/圈子/实体海报主视觉=头图，价值区放统计亮点。
- 二维码：纠错级别 M 以上，中心嵌品牌点；扫码 → 中转页分流（已装唤起/未装下载）。
- 口令短码：海报底部可视，便于截图传播时补充口令路径。

## 五、口令文案规格

- 结构来自 `link_templates.yaml` 的 `share_token`：`【趣窝圈】{body}「复制本条 {token} 打开趣窝圈App查看」`。
- 文案策略：前缀品牌钩子 + 对象一句话价值 + 口令包裹 + 行动指令；适配小红书/今日头条评论区不支持外链场景。
- 与海报二维码、短链同源 token，可互转。

## 六、适用范围与约束

- 卡片渲染纯客户端（海报）+ 微信 OpenSDK（微信卡片）；微信能力位缺失降级海报/系统分享（见 share-channel-panel）。
- private 对象不生成对外卡片；未知或已退役 visibility 严格拒绝，不生成任何物料。
- 缩略图与海报图来自 CDN 资产，禁止硬编码 URL（rule R28）。

## 七、业界对标

- 小红书/抖音：海报含二维码 + 口令双路径；微信卡片强缩略图弱文案。
- 知乎/B 站：内容卡突出标题与作者背书，主页卡突出粉丝/作品社交证明。

## 八、验收摘要

见同目录 `acceptance.yaml`：覆盖 5 类对象 × 4 渠道的卡片字段、视觉层级、降级与安全过滤。
