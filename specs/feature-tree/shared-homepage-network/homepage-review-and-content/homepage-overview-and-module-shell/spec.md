## 1. 用户价值

作为浏览、补充或维护共享主页的用户，
我希望用户可见文案禁止出现“实体”，按具体类型或对象名表达，例如 `大学 · 北京海淀`、`认识清华大学`、`大家在聊清华大学`；兜底使用“这个主页”，
从而获得可信且可持续维护的对象主页。
