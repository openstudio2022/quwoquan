# L3 Story：会话治理动作 (`session-governance-actions`)

> 所属能力：[`contact-and-session-governance`](../spec.md)

> Journey / Scenario：[`JNY-007 / SCN-012`](../../../spec.md#scn-012)

> 设计归属：[L2 DEC-001](../design.md#dec-001)

## 1. 用户价值

作为发起或接收消息的用户，
我希望能够静音、置顶、归档或删除自己可管理的会话，并得到确定的权限与状态结果，
从而稳定完成会话、消息或通话协作。

## 2. 范围与非目标

### In Scope

- “会话治理动作”的输入、可观察主路径、失败语义以及与父能力的交接。

### Out of Scope

- 父能力中由其他 Story 独立拥有的行为、能力级架构决定和实现任务。

## 3. 行为要求

<a id="req-001"></a>
### REQ-001 会话治理动作

- “会话治理动作”必须通过父能力公开契约交付可观察结果；失败时返回 canonical failure，不写入成功事实。

<a id="req-002"></a>
### REQ-002 服务本地契约引用边界

- 跨边界字段、operation 与错误语义只引用所属服务 contracts；本节点不得复制 wire 定义。

## 4. 契约引用

- 父能力公开契约：[`L2 spec`](../spec.md)。

## 5. 验收场景

<a id="gwt-001"></a>
### GWT-001 会话治理动作

- GIVEN 发起或接收消息的用户具备有效身份，且父能力声明的输入与上游事实成立。
- WHEN 参与者执行“会话治理动作”对应的公开行为。
- THEN 通过父能力公开契约交付“会话治理动作”的可观察结果。
- AND 失败时返回 canonical failure，且不产生伪成功事实。
