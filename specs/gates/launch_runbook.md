## 1. Go/No-Go 判定清单（W2 周日 + W3 周日各执行一次）

每项为 PASS/FAIL/降级，FAIL 任一 P0 即不得全量开放。

### 1.1 合规与上架（P0 外部阻断）
- [ ] 隐私政策 / 用户协议 / 权限用途 / 第三方 SDK 清单 URL 全部 200 可达
- [ ] ICP / 算法备案确认
- [ ] 双端正式签名上架包可产出（Android AAB / iOS IPA，`APP_DATA_SOURCE=remote`）
- [ ] 双端图标 / 启动图 / 应用显示名一致
- [ ] 测试账号可走通五条主旅程
- [ ] iOS PrivacyInfo.xcprivacy 就位

### 1.2 主旅程与体验（P0）
- [ ] 五条主旅程真机回归通过（A 登录 / B 推荐对象承接 / C 小趣解释 / D 搜索 / E 会话）
- [ ] 无可见「开发中 / 待接入」入口（释放白名单口径）
- [ ] 用户级举报 / 拉黑可真实提交（已接 Remote）

### 1.3 数据与差异化（P0）
- [ ] 分享归因 share_id/utm 落库且回流可归因（T6.2）
- [ ] pageVisitId 非空、页级漏斗可归因（T6.1，已落地客户端）
- [ ] Creator Impact v0 可见且数字全部来自真实信号（T5.1/T5.2）
- [ ] 交集解释首屏可感知 + 下一步动作显性（T5.3）

### 1.4 可观测与发布（P0）
- [ ] launch dashboard 无伪造趋势（T7.1，已替换 Overview 合成数据）
- [ ] launch 必看指标接真实源或显式空态
- [ ] ACK prod 灰度（initial→full）→SLO gate→auto rollback 演练有 recorded 证据（T8.2，需云账号）
- [ ] gamma-local 左移 T3/T4 有 recorded 证据（T8.1）

### 1.5 运营就绪（P0）
- [ ] 官方内容首批排产入库，首页质量锚 / 专题锚 / 对象页锚有供给
- [ ] 客服入口 + FAQ + 举报处置 SLA 就绪
- [ ] launch room 值班表确认

## 2. 降级预案（任一 P0 未达标触发）

| 触发条件 | 降级动作 |
|---|---|
| 合规/上架物料 W1 周三未就绪 | Android 先行（iOS 延后）或邀请制受控开放 |
| Creator Impact v0 未达标 | 隐藏影响力面板入口，仅保留消费端可解释，发布后补 |
| 分享归因未落库 | 分享保留但不主推「带人回流」叙事，传播类影响力维度隐藏 |
| ACK 真实演练无证据 | 不全量；继续内测 + 完成 gamma-local 左移，下个窗口再放量 |
| 端侧崩溃率 / 关键 API 错误率超阈值 | 灰度回滚到上一稳定配置，停止放量 |

## 4. 用户创作激活规则（首发）

### 4.1 种子创作者
- 招募校园 KOC（在校学生）、旅行 KOC（出行达人）各一批；建立专属对接群。
- 激励以「可见影响力」为核心：定期推送 Creator Impact 摘要（你的内容帮到了谁、促成了什么行动）。

### 4.2 任务与精选规则
- 对象页补完任务：围绕指定对象写真实体验，纳入对象页基础层。
- 圈子征集：围绕主题（校园/路线）发起投稿。
- 官方精选规则：真实体验 + 带对象锚点 + 有交集承接动作的内容优先精选，精选挂钩首页推荐。
- 禁止刷量：精选与影响力仅认真实有价值动作，不认裸曝光/裸点赞。

### 4.3 创作者反馈看板
- 创作者可在个人页查看 Creator Impact v0（5 类 action：决策/关系/知识/传播/交集）。
- 运营侧维护创作激活看板（创作转化率、模板选用率、对象绑定率）。

## 5. 客服 / FAQ / Launch Room

### 5.1 客服与 FAQ
- 客服入口：设置页内反馈 + 邮件/工单通道。
- FAQ 覆盖：登录/游客、隐私与权限、内容举报、账号注销、数据导出。
- 举报处置 SLA：一般 48h 内、涉敏感（色情/违法）24h 内处置并反馈。

### 5.2 Launch Room 值班
- 上线日设 launch room：研发 / 运营 / 客服 / 数据各 1 名值班。
- 每日复盘：崩溃率、关键 API 错误率、告警噪音、数据缺口、用户反馈 Top 问题。
- 值班路由：端侧体验类 SLO 告警 → 研发值班；治理类 → 运营值班。
