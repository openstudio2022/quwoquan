# 首发范围白名单与对外口径冻结单（三周双引擎发布）

> 真相源：本文件是首发“可公开主推 / 可降级 / 保底不主推”范围与对外命名的冻结单。
> 与本文件冲突的页面文案、入口、宣发口径以本文件为准；变更需走发布负责人评审。
> 关联：`[.cursor/plans/三周双引擎发布_ddae7322.content.execution.planning.md]`、`specs/feature-tree/spec.md`、`specs/00_PRODUCT_CONCEPT_SYSTEM.md`。

## 1. 主线定位（冻结）

- 一句话：把全网与你有关的优质内容和对象整理好，再按交集推荐给你；官方内容工厂保质量，用户创作保活性。
- 首发尖刀场景：`校园 + 旅游出行`，不做大而全。
- 核心差异化：双向可解释性。消费端解释“为什么推荐给我”，生产端解释“你的内容帮到了谁、促成了什么有价值行动”。

## 3. P1 可公开但允许降级（feature-flag 可隐藏）

- RTC 实时音视频
- 对象主页复杂治理 / 认领 / 维护
- 复杂组织树 / 群高级管理
- 深度助手能力（多轮工具编排、深检索）
- 复杂运营工作台
- 创作模板/提示词（P1，缺则回退普通编辑器）

## 4. P2 保底不主推（隐藏或仅保留兜底）

- 一切演示型、实验型、内部调试型入口
- 未完成迁移的能力（`prototype_mock_data` 链路；`AppContentRepository` 已于 2026-07-15 删除）
- 未实现的第三方登录入口（微信/微博/QQ/支付宝在 release 隐藏或标注）

## 5. 对外命名统一（外显口径）

| 概念 | 唯一对外名 | 禁止再出现的旧词/混名 |
|---|---|---|
| 推荐解释维度 | 交集 | 共鸣、缘分、匹配度 |
| 智能助手 | 小趣 | 私助、智多星、AI 助手、机器人 |
| 兴趣社群 | 圈子 | 群组（作为社群语义时）、部落 |
| 优质内容位 | 精选 | 精品、premium、会员专享 |
| 实体页 | 主页（对象主页/地点主页） | 详情页（作为对象承接语义时） |
| 搜索 | 搜索 | 发现搜索、全局检索（对外） |

> 说明：代码内部标识（如 premium feature flag、group entity）可保留，但**前台可见文案**必须使用“唯一对外名”。

## 6. 五条首发主旅程（冻结为验收对象）

| 旅程 | 路径 | 成功态 | 失败态 |
|---|---|---|---|
| A 首次打开/登录 | 欢迎 → 登录/游客继续 | 进入首页 | 游客可继续，不死循环 |
| B 推荐消费/对象承接 | 首页交集 → 内容详情 → 对象页/关注/评论/分享 | 完成一次有价值动作 | 空态/错误态可重试 |
| C 小趣解释 | 首页或对象上下文 → 小趣 → 解释与后续建议 | 看到“为什么推荐给你” | 不可用时结构化降级 |
| D 搜索跳转 | 搜索 → 结果 → 内容/用户/圈子/会话 | 跳转到目标 | 无结果显式空态 |
| E 消息会话 | 消息 → 会话 → 发送/接收 → 返回 | 消息送达/已读 | 失败可重发 |

## 7. 变更冻结纪律

- 设立 release 候选基线后，仅允许 P0 修复与 P1 降级开关进入发布集。
- 冻结非 P0 的结构性重构、审美优化、长债务清理、平台化改造。
- 脏变更三分类：上线必须 / 可延后 / 禁止进入发布集（在 PR 描述标注）。

## 8. 降级预案触发

- 若 W1 周三外部合规/上架物料仍 not_ready → `Android 先行` 或 `邀请制受控开放`。
- 若 Creator Impact v0 / 分享归因 / ACK 演练任一未达标 → Go/No-Go 降级开放或继续内测。
