# 三周双引擎发布 · 上线计划目录

与 `specs/gates/` 平级，集中存放**首发上线计划与落实跟踪**文档，不与工程门禁目录混用。

## 文件说明

| 文件 | 用途 |
|---|---|
| `three_week_dual_engine_launch_plan.md` | **落实状态唯一跟踪台账**（WS/T 任务、状态、证据、负责方） |
| `release_scope_whitelist.md` | 首发 P0/P1/P2 白名单、对外命名、五条主旅程、变更冻结 |
| `launch_runbook.md` | Go/No-Go、降级预案、内容排产、创作激活、客服与 launch room |

## 使用约定

- 后续落实跟踪以 `specs/launch-plan/` 为准。
- 建立开发/排查对话时，优先引用 `three_week_dual_engine_launch_plan.md` 中的 `WSx / Tx.y`。
- `specs/gates/` 下同名文件仅作为历史来源/引用保留，不属于本目录结构。
