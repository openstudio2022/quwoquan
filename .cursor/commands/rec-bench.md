# /rec-bench

推荐对标入口。

必须输出：借鉴、不借鉴、适用边界、当前差距、收敛计划，并映射到一棵树和 T1~T4 证据。

自然语言等价触发：用户直接描述与本命令目标相同的需求时，也按 `/rec-bench` 语义执行；执行前仍需按 `docs/agent_context_contract.md` 完成 Spec Entry / Pre-work Reflection，完成后按 Exit Review 收口。

协议补充：执行前按 `docs/agent_context_contract.md` 完成 Spec Entry / Pre-work Reflection；完成后按 Exit Review 输出证据、门禁结果与剩余风险。
