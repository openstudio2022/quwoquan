# 犹豫要不要专程去这片雪山？我的真实得失

> 一个走过两次的普通游客

如果你也在纠结值不值得专程跑一趟，我想先把真实感受讲清楚，再让你判断适不适合自己。

## 最打动我的

最让我心动的是傍晚那段光线，雪线一点点被染红，那一刻我真的觉得值得。性价比这种东西因人而异，但那种安静是我在别处没遇到过的。

![暮色雪线](asset://g_dusk)

## 也得说说遗憾

也有遗憾：连续几天的颠簸让我很疲惫，住宿条件也一般。怕累、怕高反的人需要有心理准备，这点我不想替谁美化。

## 适合谁、不适合谁

这地方适合愿意为风景吃点苦的人，不适合只想轻松度假的人。如果你更看重舒适，我会建议换个目的地，别勉强自己。
