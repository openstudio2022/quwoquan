# 景区主页模板使用指南

## 模板用途

本模板用于生成旅游景区类实体的主页（page.md），包括自然景观、人文景观、主题公园等。

## 适用范围

- 实体类型标签为 `实体类型/地点/景区` 的所有实体
- 包括但不限于：山岳型、湖泊型、古镇型、主题公园型、宗教圣地型

## 生成要求

- 总字数 >= 800 字
- **以百科底稿为基础适度加工（轻改）**：参考百度百科写法、按真实信息归类章节，去语病/补证据/去版权痕迹；不要从零总结。
- **结构尊重原文（底稿）**：下方 `template.md` 的章节只是**规范化参考**（用于章节命名与归类对齐），**不是必须逐节填满的清单**。可按底稿真实内容增减、合并章节。
- **仅 `概况` 必备**：其余章节有真实内容才写，**无真实内容的章节直接省略，禁止硬凑**，禁止为凑章节而编造。
- **章节须语义正确**：`历史沿革` 必须是真实历史（含年份/朝代/建置沿革等），否则省略该章节或补真实历史；**禁止把地质成因、景区评级、客流数据塞进「历史沿革」**。
- 所有信息来源于权威百科或实际考证，禁止编造
- 标签和实体引用嵌入正文中，使用 `/tag/` 和 `/entity/` 链接格式
- 图片引用使用 `asset://` 协议；**实体主页须配 ≥1 张真实 CC 图片**
- 禁止出现独立的 `## 标签` 或 `## 相关实体` 章节

## 质量约束

| 维度   | 要求                   |
| ---- | -------------------- |
| 概况（必备）   | 含经纬度范围、海拔、面积等可量化信息   |
| 历史沿革（可省略） | 若写则须为真实历史，至少 1 个真实时间节点/朝代；无真史则省略 |
| 核心景点（按底稿） | 有几处写几处，每处尽量 >= 80 字 |
| 实用信息（按底稿） | 门票/开放时间/交通/最佳季节，**有则写、缺则略**，不得编造 |
| 文化特色（可省略） | 有真实文化内涵再写，可关联非地理标签 |

## 引用规范

- 实体引用嵌入正文：`[峨眉山](/entity/地点/景区/峨眉山)`
- 标签引用嵌入正文：`[佛教文化](/tag/主题/佛教文化)`
- 图片：`![描述](asset://filename.jpg)` 或 `{asset://filename.jpg|wrapLeft|描述|width=45%}`
