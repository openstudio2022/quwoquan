# 博物馆主页模板使用指南

## 模板用途

本模板用于生成博物馆类实体的主页，包括历史博物馆、自然博物馆、科技馆、纪念馆等。

## 适用范围

- 实体类型标签为 `实体类型/地点/博物馆` 的所有实体

## 生成要求

- 总字数 >= 800 字
- **结构尊重原文（底稿）**：`template.md` 的章节只是**规范化参考**（命名与归类对齐），**非强制逐节填满**；仅 `概况` 必备，其余章节有真实内容才写、无则省略、禁止硬凑，可按底稿增减或合并。
- 常见章节（参考，非强制）：馆藏概况、镇馆之宝、参观动线——按底稿真实内容取舍。
- 标签和实体引用嵌入正文
- 禁止出现独立的标签或相关实体章节

## 质量约束

| 维度 | 要求 |
| ---- | ---- |
| 概况（必备） | 含建馆年份、面积、馆藏数量 |
| 镇馆之宝（按底稿） | 有几件写几件，每件含年代/材质/特色 |
| 参观动线（可省略） | 有则给推荐路线含时长 |
| 实用信息（按底稿） | 开放时间/门票/预约方式，有则写 |
