# 古镇主页模板使用指南

## 模板用途

本模板用于生成古镇类实体的主页，包括历史古城、传统村落、水乡古镇等。

## 适用范围

- 实体类型标签为 `实体类型/地点/古镇` 的所有实体

## 生成要求

- 总字数 >= 800 字
- **以底稿为基础适度加工（轻改）**：参考百科写法、按真实信息归类章节，去语病/补证据/去版权痕迹；不要从零总结。
- **结构尊重原文（底稿）**：`template.md` 的章节只是**规范化参考**（命名与归类对齐），**非强制逐节填满**；仅 `概况` 必备，其余章节有真实内容才写、无则省略、禁止硬凑，可按底稿增减或合并。
- **章节须语义正确**：`历史沿革` 须为真实历史，否则省略。
- 标签和实体引用嵌入正文
- 禁止出现独立的标签或相关实体章节

## 质量约束

| 维度 | 要求 |
| ---- | ---- |
| 概况（必备） | 含建镇年代、面积、现存古建数量等可量化信息 |
| 历史沿革（可省略） | 若写须为真实历史，至少 1 个真实时间节点/朝代；无真史则省略 |
| 核心看点（按底稿） | 有几处写几处，含建筑特色 |
