# Bundled fonts (offline Web)

Fonts in this tree are declared in `bundled_fonts_manifest.yaml` and registered in `pubspec.yaml`.

## Commands

```bash
make fetch-app-bundled-fonts
make verify-app-bundled-fonts
make check-app-bundled-fonts-updates
make verify-app-web-offline-resources
```

All commands delegate to `python3 quwoquan_app/scripts/cli.py`.
