# operations · dev · product-ops

- [MUST] 运营事实只经本领域公开 command 写入，跨域写入改走目标领域公开 command。
  check: 读取新增写入路径与被写对象 owner；直写其他领域存储或复制其状态账本时判失败。
- [MUST NOT] 以指标、建议或缓存替代业务成功事实与已发布版本事实。
  check: 读取终态与版本事实的取值来源；非目标领域公开结果而来自指标或本地推断时判失败。
- [MUST] 事件、实验与审计事实保留声明身份、脱敏边界与可重放性。
  check: 读取新增字段与其契约声明；身份缺失、字段未声明或携带 PII/secret 时判失败。
- [SHOULD] 可热调项限于已声明热调层，拓扑与依赖身份不改成运营开关。
  check: 读取新增可调项声明位；服务名单、依赖或物理地址进入热调面时判失败。

正文与违规案例见 `references/guides/product-ops.md`。
