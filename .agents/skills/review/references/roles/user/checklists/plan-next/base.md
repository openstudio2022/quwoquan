# user · plan-next · base

## POST 自检

- [MUST] 本轮交付的用户可见变化已逐条对照：用户此刻真实能完成什么、哪里还会卡住
  check: 结论只有「功能已实现」而无用户视角的可完成/会卡住判断，判失败
- [MUST] 用户会卡住的断点（登录环、空态死路、报错无出路）要么已修，要么转 `OPEN-###`
  check: 已知断点既未修复也无 OPEN，判失败
- [SHOULD] 下一轮计划中的用户价值排序有依据（频次、阻断程度），不是纯工程顺序

## HANDOFF 交接

- 产出：用户视角残量清单
- 未决项去向：全部落 OPEN / Out of Scope / 下一轮计划
- 下一步：POST 评审汇总
- 证据链：断点核对记录
