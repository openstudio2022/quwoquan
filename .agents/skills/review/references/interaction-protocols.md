# 五个交互协议（skill 调用与 vibe coding 同标准）

会话内行为约定，按时序覆盖做前/做中/做后。决策原则一条不新造，全部引用宪法与 checklist
既有条款；本文件只规定何时对照、如何分级。完成判据的唯一定义见
[completion-criteria](completion-criteria.md)。

## 1. 做前反串讲（brief-back）

执行前在会话内呈现固定五项：任务目标、生效约束（宪法/规格/棘轮关键项）、预期输出、
验证判据（引用完成判据表的具体命令）、不做什么的承诺。**呈现即继续，默认不等待确认**；
人可读、可随时打断补充；纯查询豁免。写不出验证判据 = RESOLVE 未完成，不许开工。

## 2. 澄清归宿

沿用 [decision-tree-interview](../../explore/references/decision-tree-interview.md)：
事实 agent 自己查，决策才问人。改变规格的澄清决策进 spec（prd 工作流）；改变本轮范围的
进交接单 intent 终版记录；其余留会话内。frontier 残项显式列为风险。
新澄清与已记录决策矛盾时呈报用户裁决，禁止默默取后者。

## 3. 漂移升版

新口令实质改变意图时，必须显式声明「范围 vN→vN+1 及原因」再继续；静默扩围是可判定的
违规形态，POST 评审以 check 复核。

## 4. 执行中三级裁决

三个自检时机：每完成一个子任务、每次意外失败、每次准备扩大改动面。对照反串讲五项承诺，
任一不再成立即进入三级裁决：

- **自行处理并继续**：修复在反串讲范围内 + 不触并行会话正在改的路径 + 不增棘轮残量 +
  不造第二真相源/重复轮子。
- **登记后继续**（不阻塞但零悬空）：真缺口但超本轮范围 → 三向裁决进交接报告，
  禁止顺手扩围修复。
- **停下问人或回上游工作流**：需改规格/DEC（回 `prd`/`design`）、与已记录澄清决策矛盾、
  高危动作、代码 owner 不唯一、修复必然增加棘轮残量或必须跨并行路径。

跨界判定是运行时事实查证（agent 自查不问人）：`git status` 并行会话改动交集 +
本轮 scope 的 owner 路径；必须动并行会话触碰中的文件时不硬改，走第 2/3 级。

## 5. 做后交接报告 + 轮次交接单

轮次结束在会话内呈现人读摘要：做了什么与验证结果、发现的全部问题及三向裁决
（零悬空：修复了 / 转 `OPEN-###` / 下轮承接）、棘轮残量变化（增加必须显式说明理由）、
是否触发新一轮的判定及依据。同一内容落交接单
`.qwq_output/env/repo/runs/handoff/<轮次>/manifest.md`（宪法 HANDOFF 四项的结构化形态，
运行产物可删可重建；长期事实必须同时转出到 OPEN/spec），用
`make verify-handoff-manifest` 校验后交接；下轮 RESOLVE 强制消费，证据 SHA 过期即复跑。
纯查询会话豁免交接单。

同类缺口或用户同类纠正第二次出现 → 触发 distill 回写提议；回写永远是
「提议 + 人确认 + prd/dev 正常工作流」，agent 不得绕过工作流直接修改规则资产。

## 6. 评审取证：本地视图不可当真相

评审员（含 reviewer 子代理沙箱）就 git 状态下 finding 前，必须用权威命令取证，
不得凭工作树表象或跟踪 ref 推断——曾有两条 finding 因此被驳回（沙箱物化 symlink、
跟踪 ref 陈旧误判未推送）：

- 是否已推送：`git ls-remote <remote> <branch>` 直查远端，跟踪 ref（`origin/...`）
  可能陈旧，`git status` 的 ahead/behind 不作数。
- 文件形态（symlink/普通文件）：`git ls-files -s <path>` 看 index mode
  （120000=symlink），沙箱与检出视图可能把 symlink 物化为目录。
- 提交内容归属：以 `git log` / `git show` 的提交事实为准，工作树脏改动不代表提交内容。

取证不到权威证据时，finding 降级为问题（question）而非断言（violation）。
