# 阶段契约：2.quality

## PRE

- `1.download` CLOSE 为 pass。
- AI 在 OPEN 显式冻结 source units/source refs、下载/CAS holdings、source policy 与对象 target refs。

## DURING

AI 逐素材与逐事实判断保留/淘汰，写对象级 `2.quality/quality_analysis.json`。每个保留事实绑定 source unit 内的可复核锚点；每个淘汰项写明原因。不得引用未下载、摘要漂移、已淘汰或无来源锚点的素材/事实。

## POST

```bash
python3 quwoquan_data/scripts/cli.py verify stage-artifacts --execution-id <id> --through 2.quality
```

AI 另做语义自检：事实是否被来源支持、媒体是否满足目标用途、保留集是否足以进入 compose。脚本不得替 AI 生成质量结论。

## HANDOFF

- `resultRefs`：逐对象 quality analysis。
- pass 后由 Skill 固定进入 `3.compose`；不足则 blocked，并由新 execution 重新开始。
