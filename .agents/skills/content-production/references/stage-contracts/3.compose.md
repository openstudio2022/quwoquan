# 阶段契约：3.compose

按 prompts/templates 组装 writing pack（创作输入包）。

## 身份

- stage：`3.compose`（与磁盘目录一字不差）
- 前置阶段：`2.quality`
- 合法 next：`4.draft`
- 角色人设：宿主 agent（选材与结构化，无独立人设）
- 写目录 allowlist：对象级 `3.compose/`

## 做前（PRE）

- `2.quality` receipt `verdict=pass`；复跑：

```bash
python3 quwoquan_data/scripts/cli.py verify stage-artifacts --execution-id <id> --through 2.quality
```

## 做中（DURING）

- 按 `quwoquan_data/prompts/`、`quwoquan_data/templates/` 组装对象级
  `3.compose/` 产物：homepage lane 为 `entity_page_input.json`，
  article/image/video lane 为 `writing_pack.json`
  （清单真相源：`stage_artifact_contract.py`）。
- 确定性组装优先走 CLI；agent 只做需要语义判断的选材与结构化。
- [MUST NOT] 混入 `2.quality` 保留集之外的素材或事实。
- [MUST NOT] 在 pack 中引入来源锚点缺失的内容。

## 做后（POST）

交付件：每对象 `3.compose/` writing pack。完成判据：

```bash
python3 quwoquan_data/scripts/cli.py verify stage-artifacts --execution-id <id> --through 3.compose
```

常见 issue → 修复：

- pack 缺失/命名不符 → 按 lane 契约补齐正确文件名。
- 引用素材不在保留集 → 从 pack 移除或回 `2.quality` 重新判定。

按 [handoff-protocol.md](../handoff-protocol.md) 落 receipt。
