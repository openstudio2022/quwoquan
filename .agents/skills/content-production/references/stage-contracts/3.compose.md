# 阶段契约：3.compose

AI 全权选择已保留素材与事实，形成创作输入包；脚本不得替 AI 选材或组装语义内容。

## PRE

- `2.quality` CLOSE 为 pass。
- OPEN 显式冻结 target、quality analysis、保留 source refs、prompt/template/policy refs 与 creator/tag bindings。

## DURING

AI 逐对象选择材料、结构、角度、事实和媒体位置：homepage 写 `entity_page_input.json`；article/image/video 写 `writing_pack.json`。pack 必须只引用 quality 保留集，显式绑定事实锚点、creator/tag/entity/media identity 与目标载体要求。

video pack 必须给出后续 `video_script` 的叙事/镜头输入，不能以“无正文创作”为由省略 AI compose。任何确定性 CLI 只能校验/落盘，不得替 AI 决定选材。

## POST

```bash
python3 quwoquan_data/scripts/cli.py verify stage-artifacts --execution-id <id> --through 3.compose
```

AI 自检引用闭包、选材充分性、事实边界与载体契约，再提交 verifier facts 与 verdict。

## HANDOFF

- `resultRefs`：逐对象 compose pack。
- pass 后由 Skill 固定进入 `4.draft`。
