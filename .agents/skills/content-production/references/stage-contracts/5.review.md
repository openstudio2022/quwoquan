# 阶段契约：5.review

独立评审：rubric 质量判定 + 逐图权利复核。

## 身份

- stage：`5.review`（与磁盘目录一字不差）
- 前置阶段：`4.draft`
- 合法 next：`publish`（rejected 对象 → `return_to_stage:4.draft`）
- 角色人设：[quality-reviewer](../roles/quality-reviewer.md) 与
  [rights-reviewer](../roles/rights-reviewer.md)（独立会话）
- 写目录 allowlist：对象级 `5.review/`

## 做前（PRE）

- `4.draft` receipt `verdict=pass`；复跑其判据命令（按本 execution 的 lane
  取 [4.draft.md](4.draft.md) POST 栏对应那条，完整 argv 同栏）。
- 读 `4.draft` receipt 的 `actor.modelFamily`，按
  [orchestration.md](../orchestration.md) 的「异族 judge 派发面」派发**宿主子会话**
  并显式传入不同族的 model slug。
- [MUST NOT] author 会话自评。
- [MUST NOT] 在 judge 会话上用 `auto` 让宿主自行路由——`auto` 不保证族别，
  拿不到具名异族 slug 时本阶段直接 `verdict=blocked`，不得先评后补。

## 做中（DURING）

- rubric 逐条二元判定 + 理由，写对象级 `5.review/` 产物
  （清单真相源：`stage_artifact_contract.py`；rubric 结果含 judge 元数据）。
- rights：逐图授权与商用范围复核，结论落盘。
- Review 归因顺序（`quwoquan_data/AGENTS.md`）：先判证据是否充足，再判
  prompt/template 失配，最后才判创作执行问题；不同归因回退到不同阶段。
- [MUST NOT] 评审中修改正文；[MUST NOT] 用 approve 掩盖证据缺口。

## 做后（POST）

交付件：rubric 评审结果 + rights 结论 + `5.review/` 契约产物。完成判据：

```bash
python3 quwoquan_data/scripts/cli.py verify rubric --file <rubric结果路径> \
  --generation-family <4.draft 实际生成族>
python3 quwoquan_data/scripts/cli.py verify stage-artifacts --execution-id <id>
```

常见 issue → 修复：

- judge 与 generator 同族 → 重派异族 judge 会话重评，不改 rubric 文件。
- 判定缺理由/非二元 → 补齐该条判定的理由字段。
- 宿主 CLI 报 `Named models unavailable` → 该宿主不具备本阶段派发能力，改用
  具备具名 slug 的子会话派发面；不得退回 `auto` 评审。

按 [handoff-protocol.md](../handoff-protocol.md) 落 receipt。

## 交接（HANDOFF）

- receipt `actor` 记录 judge 会话与模型族。
- rejected 对象 → `openItems` 登记 `return_to_stage:4.draft`（draft↔review
  往返全局 ≤3 轮，超限 `verdict=blocked`）。
- 全部 approved → `next=publish`。
