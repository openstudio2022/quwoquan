# 阶段契约：0.plan

核验并记录 `task init` 已冻结的区域、数量、目标集与阶段范围。

## 身份

- stage：`0.plan`（与磁盘目录一字不差）
- 前置阶段：无（工作包起点）
- 合法 next：`sources`
- 角色人设：[planner](../roles/planner.md)
- 写目录 allowlist：无新产物；三份 init artifact 均由 `task init` create-once
  写入，本阶段零写盘（receipt 除外）

## 做前（PRE）

- 工作包必须已由中性 `task init` 原子创建，三份 init artifact ref/digest 与 immutable candidate binding 一致；命令失败或三文件字节漂移时本 PRE 必须 `GATE_BLOCK`。
- 不运行仓内 semantic provider、Cursor key/model、SDK、capacity 或 workspace soak preflight；仅验证本 stage 的 deterministic input/layout。
- family recipe 存在且不含区域/日期/executionId（recipe 只声明可复用参数）。
- executionId 符合 [execution-layout.md](../execution-layout.md) 命名；重试时
  manifest 声明 `retryOf`。

## 做中（DURING）

- 只核验/记录 `task init` 冻结的 `0.plan/request.json`、`0.plan/target_set.json`
  与根 `execution_manifest.json`：区域范围、数量配额、目标集、阶段范围。
- 目标集结构以 `quwoquan_data/schema/` 对应 schema 为准，skill 不复制字段。
- [MUST NOT] 改写、重写或补写上述三文件——它们是 create-once init artifact，
  字节漂移即 `GATE_BLOCK`。
- [MUST NOT] 把省份、日期、实体或输出路径写回 recipe。
- [MUST NOT] 创建平行任务身份（taskId/batchId/planId/workerId）。

## 做后（POST）

交付件：上述三文件。完成判据（退出码 0）：

```bash
python3 quwoquan_data/scripts/cli.py verify runtime-input-ownership
python3 quwoquan_data/scripts/cli.py verify task-init-contract --execution-id <id>
```

常见 issue → 修复：

- `task-init document executionId drift` → 丢弃该工作包并以新的 execution sequence 重跑 `task init`。
- 区域/数量出现在 recipe → 从 recipe 移除，改经 CLI 参数进入 request.json。

按 [handoff-protocol.md](../handoff-protocol.md) 执行 `task stage-open` → `task stage-gate` → `task stage-close`；宿主不填写 command 退出码、verdict 或 next。
