# 阶段契约：4.draft

Agent 基于 sources + writing pack 创作正文。

## 身份

- stage：`4.draft`（与磁盘目录一字不差）
- 前置阶段：`3.compose`
- 合法 next：`5.review`
- 角色人设：[content-author](../roles/content-author.md)
- 写目录 allowlist：对象级 `4.draft/`

## 做前（PRE）

- `3.compose` receipt `verdict=pass`；复跑：

```bash
python3 quwoquan_data/scripts/cli.py verify stage-artifacts --execution-id <id> --through 3.compose
```

- author 会话就位（A 档为当前会话或子会话；B/D 档为本轮 loop 会话）。

## 做中（DURING）

- 只基于 `sources/` 与本对象 writing pack 创作；产物标记 `generator=agent`
  （Post manifest schema 单轨，DEC-004）。
- 对象级 `4.draft/` 产物清单真相源：`stage_artifact_contract.py`
  （homepage 为 `page.md`，article 为 `draft.article.md`，均含 draft 元数据
  与事实引用映射）。
- 遵守 `quwoquan_data/AGENTS.md` 质量禁令：禁止百科罗列、机械收尾、模板化
  小标题、来源痕迹、未经改写长句复现。
- [MUST NOT] 引入 pack 外事实；[MUST NOT] 由脚本生成、拼接或填充正文。
- [MUST NOT] 输出包含凭证、key 片段或指纹。

## 做后（POST）

交付件：正文 + 事实引用映射。完成判据**按 lane 绑定，不得任选**；
`stage-artifacts` 两条 lane 都要跑，homepage 只是额外多一条逐实体正文判据：

```bash
# 全 lane 通用：产物清单闭合
python3 quwoquan_data/scripts/cli.py verify stage-artifacts --execution-id <id> --through 4.draft
# homepage lane 追加（逐实体，每个实体都要过）
python3 quwoquan_data/scripts/cli.py verify homepage-draft --execution <id> --entity <e>
```

`homepage-draft` 判的不只是字数与章节均衡，还包括两条派生度判据（真相源
`specs/feature-tree/discovery-content/object-homepage-coverage-scaling/on-demand-content-pool-admission/spec.md#req-003`）：

- **源文本重合度**（`sourceParagraphOverlap`）：单个正文段落相对底稿
  `source.clean.md` 的逐字重合越线即判否，issue 点名该正文段落序号与底稿行号区间。
  整篇 `baseDraftFidelity` 不覆盖这条：一段照抄会被其余重写段落稀释到线下。
- **正文内部重复**（`intraBodyParagraphRepetition`）：正文任意两段的相似度越线即
  判否，issue 点名两个段落序号。改掉两个词的复读在精确去重下不可见，因此必须独立判。

两条判否线与参与判定的段落最小字数由 `quwoquan_data/verticals/<vertical>/content_policy.yaml`
的 `quality` 段声明（`homepageMaxSourceParagraphOverlap`、
`homepageMaxIntraBodyParagraphSimilarity`、`homepageDerivationParagraphMinimumChars`），
判据代码不持有默认值。字数达标不构成放行理由——凑够字数的复述原文与复读都会判否。

homepage lane 不得只跑 `homepage-draft` 就落 pass：`5.review` 的 PRE 会跑
`stage-artifacts --through 4.draft`，它要求 `author_self_check.json` 与
`agent_result_envelope.json` 等 author 证据在场。POST 弱于下一阶段 PRE 会让每条
lane 先通过再被退回，白跑一个来回，因此判据在本阶段就必须对齐。

常见 issue → 修复：

- 底稿贴合度不足 → 对照 issue 点名的段落，回到 pack 内来源重写该段。
- `sourceParagraphOverlap` → 打开 issue 点名的底稿行号区间，只保留那几行的**事实**，
  用自己的表述重新组织该段。压缩、删词或调整语序不会让重合度下降，逐字片段仍在。
- `intraBodyParagraphRepetition` → 两段里删去信息量较低的那一段，或把它改写为该段
  独有的事实。不要靠替换同义词规避，判据按逐字片段度量而不是按用词。
- `sourceParagraphOverlap: 底稿正文文件不可定位` → 不是正文问题：先确认
  `3.compose/entity_page_input.json` 的 `baseDraft.primaryEvidenceRef` 指向真实
  来源单元、且 `1.download` 下该单元的 `source.clean.md` 在场，再重跑自检。
- 结构缺件（draft_meta、author_self_check、agent_result_envelope 等）
  → 按 `stage_artifact_contract.py` 清单补齐对应文件。

按 [handoff-protocol.md](../handoff-protocol.md) 执行 `task stage-open` → `task semantic-prepare --stage 4.draft` → 宿主语义工作 → `task semantic-record --stage 4.draft --input <json>` → `task stage-gate`（context 只绑定 canonical `semanticResultRef + semanticResultDigest`）→ `task stage-close`；宿主不填写 command 退出码、verdict、next 或自由 input refs。

## 交接（HANDOFF）

- `agent_result_envelope.json` 作为 gate artifact exact binding；close 从其 actor evidence 派生实际生成模型族。
- `next=5.review`。
