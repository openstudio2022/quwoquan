# 阶段契约：4.draft

## PRE

AI 在 OPEN 只提交并冻结对象 compose pack、其引用的 source/quality refs 与载体写作政策 exact refs。

## DURING

宿主 AI 直接创作并写对象级产物：

- homepage：`page.md`；
- article：`draft.article.md`；
- image：`image_work.json`，包含 AI 创作的 caption/work 文本；
- video：`video_script.json`，包含 title、caption、可执行叙事、镜头/画面与声音/字幕意图。

每对象同时写 `draft_meta.json`、`author_self_check.json` 与 `agent_result_envelope.json`。正文/caption/script 只能使用 OPEN 冻结证据，不得由脚本、模板填充器或 processor 合成。

## POST

机械 verifier：

```bash
python3 quwoquan_data/scripts/cli.py verify stage-artifacts --execution-id <id> --through 4.draft
```

AI self-check：事实忠实、非抄录、非模板化、结构完整、caption/script 可用、媒体引用与载体目标。缺任一载体正文对象、draft meta、self-check 或 agent envelope 均 blocked。

## HANDOFF

- receipt ref/digest；
- `resultRefs`：载体正文对象、draft meta、self-check、agent result envelope exact refs/digests；
- `typedIssues`；
- Skill 固定后继：`5.review`。
