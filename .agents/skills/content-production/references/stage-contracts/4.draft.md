# 阶段契约：4.draft

## PRE

- `3.compose` CLOSE 为 pass。
- OPEN 显式冻结对象 compose pack、其引用的 source/quality refs 与载体写作政策。
- 不要求 `author_job_packet`、`prompt.md` 或 `prompt_snapshot`；这些不是本阶段 authority。

## DURING

宿主 AI 直接创作并写对象级产物：

- homepage：正文 `page.md`；
- article/image：对应正文或 caption/work 文本；
- video：明确写 `video_script`，包含可执行叙事、镜头/画面与声音/字幕意图。

每对象同时写 `draft_meta.json`、AI `self_check` 与 `agent_result_envelope.json`。正文/脚本只能使用 OPEN 冻结证据，不得由脚本、模板填充器或 processor 合成。

## POST

```bash
python3 quwoquan_data/scripts/cli.py verify stage-artifacts --execution-id <id> --through 4.draft
```

AI 自检事实忠实、非抄录、非模板化、结构完整、媒体引用与载体目标，并提交逐条 verifier facts。缺正文/`video_script`、draft meta、self-check 或 agent result envelope 均 blocked。

## HANDOFF

- `resultRefs`：正文或 `video_script`、draft meta、self-check、agent result envelope。
- pass 后由 Skill 固定进入 `5.review`。
