# 阶段契约：4.draft

## PRE

AI 在 OPEN 只提交并冻结对象 compose pack、其引用的 source/quality refs 与载体写作政策 exact refs。

## DURING

一个 execution 的本阶段必须由一个真实 author actor 会话负责全部对象。宿主 Agent 直接创作，每对象只写以下一个 carrier 主产物：

- homepage：`page.md`；
- article：`draft.article.md`；
- image：`image_work.json`，包含 AI 创作的 caption/work 文本；
- video：`video_script.json`，包含 title、caption、可执行叙事、镜头/画面与声音/字幕意图。

不得再写 `draft_meta.json`、`author_self_check.json` 或 `agent_result_envelope.json`。正文/caption/script 只能使用 OPEN 冻结证据，不得由脚本、模板填充器或 processor 合成。author 的真实 actor/invocation、逐对象 self-check，以及 prompt/compose/draft exact refs/digests 统一在 sequence-006 CLOSE receipt 冻结。

## POST

机械 verifier：

```bash
python3 quwoquan_data/scripts/cli.py verify stage-artifacts --execution-id <id> --through 4.draft
```

AI self-check：事实忠实、非抄录、非模板化、结构完整、caption/script 可用、媒体引用与载体目标。缺任一对象的 carrier 主产物，或 execution 内出现多个 author actor/session/runId，均 blocked；self-check 不另写业务文件。

## HANDOFF

- receipt ref/digest；
- `resultRefs`：每对象唯一 carrier 主产物 exact ref/digest；sequence-006 receipt 同时冻结真实 author actor/invocation、自检与 prompt/compose/draft digests；
- `typedIssues`；
- Skill 固定后继：`5.review`。
